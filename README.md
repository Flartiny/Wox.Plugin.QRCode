# QRCode

在 Wox 中快速生成二维码：输入文本或链接，实时预览二维码图案，一键复制到剪贴板或保存为 PNG 图片；`qrlist` 可查看历史生成记录并快速复用。

## 安装

```sh
wpm install QRCode
```

## 用法

- 输入 `qrcode <内容>` 生成二维码，例如 `qrcode https://example.com`
- 选中任意文本后按热键调起 Wox，也可直接为该文本生成二维码（需在 Wox 设置中启用「选中文本查询」）
- 输入 `qrlist` 查看历史生成记录（最近使用优先，相同内容自动去重）；输入 `qrlist <关键词>` 可按内容过滤

生成结果操作：

| 按键     | 操作                    |
| -------- | ----------------------- |
| `Enter`  | 复制二维码图片到剪贴板  |
| `Ctrl+S` | 保存二维码为 PNG 到目录 |
| `Ctrl+C` | 复制二维码内容文本      |

历史列表操作：

| 按键     | 操作                      |
| -------- | ------------------------- |
| `Enter`  | 复制该条记录的二维码图片  |
| `Ctrl+S` | 保存该条记录为 PNG 到目录 |
| `Ctrl+C` | 复制该条记录的内容文本    |
| `Ctrl+D` | 从历史中删除该条记录      |

历史列表底部提供「清空历史记录」入口（内容为空时提示）。

## 设置

| 设置项       | 说明                                                             |
| ------------ | ---------------------------------------------------------------- |
| 二维码尺寸   | 生成图片的边长（像素），可选 256 / 512 / 1024                    |
| 容错等级     | L(7%) / M(15%) / Q(25%) / H(30%)，越高越耐污损                   |
| 历史记录条数 | `qrlist` 历史记录最多保留条数（10-200，默认 50），超出后淘汰最旧 |
| 保存目录     | 执行「保存为 PNG」时的存放位置，留空则保存到系统下载目录         |

## 开发

```bash
make install   # 安装依赖
make build     # 构建
make test      # 运行测试
make package   # 打包为 wox.plugin.QRCode.wox
```

## 技术说明

- 使用 [qrcode](https://www.npmjs.com/package/qrcode) 纯 JS 生成 PNG，无系统依赖
- 生成结果缓存在 Wox 数据目录（`%APPDATA%\Wox\Data\qrcode-cache`）下，相同内容复用同一文件，最多保留 30 个；历史图片缺失时会按需重新生成
- 历史记录独立存储在 `%APPDATA%\Wox\Data\qrcode-history.json`（缓存文件名是内容哈希，无法还原文本），以最近使用排序、相同内容去重，条数可在设置中调整
